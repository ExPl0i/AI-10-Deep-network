# Глубокая сеть: слой, активация, XOR

Занятие курса «Искусственный интеллект» для 10 класса (практическая работа №1, часть 1С). Ученики пишут прямой проход полносвязной нейросети на «голых» тензорах PyTorch, убеждаются, что без нелинейности сеть не решает задачу XOR, а с ReLU решает, и сверяют свой код с готовыми слоями `torch.nn`.

## Теория (презентация)

1. **Нейрон и слой** – нейрон как логистическая регрессия, слой из многих нейронов, тензоры и их формы.
2. **Нелинейность и глубина** – зачем нужна активация, почему два линейных слоя дают прямую, решение XOR с ReLU, глубина экономит нейроны.
3. **Выход и потери** – выбор выходного блока по задаче, softmax, подсчет параметров сети.
4. **Пишем сеть на Python** – структура данных, план практики.

## Практическая работа

Сквозной пример – функция XOR на четырех точках и веса сети из книги Гудфеллоу и др. (раздел 6.1).

1. Функции активации, softmax и кросс-энтропия.
2. Линейный слой.
3. Сеть для XOR.
4. Подсчет параметров сети.
5. Сверка с `torch.nn`.
6. Граница решений на данных «две луны».

Задания повышенной сложности: устойчивый `log_softmax`, сеть без активации на «лунах», доказательство, что сеть с одним скрытым нейроном не решает XOR.

**Правило работы:** внутри своих функций – только операции тензоров (`@`, `+`, `-`, `*`, `/`, `torch.maximum`, `torch.exp`, `torch.log`, `.sum`, `.max`). Готовые `nn.Linear`, `torch.relu`, `torch.softmax`, `F.cross_entropy` – только в задании С5 и в готовой ячейке обучения С6.

## Как работать

1. Откройте ноутбук в Jupyter или Google Colab.
2. В ячейках с заданиями замените `...` своим кодом (подсказка – в комментарии `# <--`).
3. Сверьте напечатанное значение с тем, что указано после слова «ожидается».
